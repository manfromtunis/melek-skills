# Obsidian GTD Lite Reference

## Suggested file structure

```text
00 - Inbox/
  Inbox.md
01 - Projects/
  Clip2earn/
  ContentForge/
  Bakchich/
02 - Areas/
  Admin/
    Waiting For.md
    Watchlist.md
03 - Resources/
  Weekly Review.md
```

## Inbox

Use Inbox for:
- messy capture
- thoughts
- things to sort later
- task fragments from chat or email

## Waiting For

Use for:
- delegated items
- pending replies
- follow-ups
- things blocked on another person

Recommended fields or bullets:
- Person
- Subject
- Since
- Next relance date

## Watchlist

Use for:
- maybe later
- ideas
- low-priority opportunities
- things to revisit

## Weekly Review

Recommended sections:
- Inbox to clarify
- Waiting For to relance
- Project review
- Upcoming deadlines
- Next week priorities

## Daily note template

```markdown
# YYYY-MM-DD - Prioritized Tasks

## Q1: DO NOW (Urgent + Important)

## Q2: SCHEDULE (Important, Not Urgent)

## Q3: BATCH (Admin - 30min block)

## Q4: DEFER

## Today's Focus (Top 3)
1.
2.
3.

## Completed
```

## Classification rule

If a task has a hard date/time and truly belongs on a schedule, put it on Calendar.
If it is actionable but flexible, keep it in the daily note or project system.
